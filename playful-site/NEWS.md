# お知らせの更新

お知らせの本文は `news.json` のみを編集します。生成コマンドでトップページとお知らせ一覧の両方に反映されます。

## 追加手順

1. `news.json` の配列に、次の形式で記事を追加します。記事同士の間にはカンマが必要です。

   ```json
   {
     "id": "business-hours-20261010",
     "date": "2026-10-10",
     "category": "営業案内",
     "title": "お知らせの見出し",
     "body": [
       "お知らせの本文を記入します。",
       "段落を分ける場合は、文字列を追加します。"
     ],
     "draft": true
   }
   ```

2. 公開する際は `"draft": true` を `"draft": false` に変更するか、項目を削除します。
3. リポジトリのルートで、次を実行します。Node.js 20以降が必要です。追加パッケージは不要です。

   ```powershell
   node playful-site/scripts/build-news.mjs
   ```

4. `playful-site/index.html` と `playful-site/news.html` を開いて表示を確認します。公開先には生成後の両HTML、共通CSS・JS、追加した添付ファイルを一緒に反映します。

## 表示ルール

- トップページには、公開記事を日付の新しい順に2件表示します。件数は `scripts/build-news.mjs` の `LATEST_COUNT` で変更できます。
- `news.html` には公開記事をすべて残し、年別・日付の新しい順に表示します。最新年だけ最初から開きます。
- 同じ日付の記事は `news.json` の記載順になります。
- `important: true` で重要表示になります。掲載順やトップの件数は変わりません。
- `draft: true` の記事は生成HTMLに含めません。ただし `news.json` 自体は機密情報の保管場所ではありません。未公開の機密情報は書かないでください。
- 日付は表示・並べ替え用です。未来の日付を設定しても予約公開にはなりません。公開までは下書きにしてください。
- `id` は重複しない半角英小文字・数字・ハイフンで指定します。公開後は変更しないでください。直接リンクは `news.html#news-ID` です。
- 本文は通常の文章です。HTMLタグは実行されず、そのまま文字として表示されます。
- 過去のお知らせは当時の案内として残します。料金や現在の営業時間が変わる場合は、トップページの料金・アクセス欄も別途更新します。

## 電話・画像・資料の追加

必要な項目だけ、記事内へ追加してください。`news.json` の既存記事にも例があります。

```json
"phone": {
  "number": "070-2615-9280",
  "hours": "受付 8:00–17:00"
},
"links": [
  {
    "text": "ご案内の画像を見る",
    "href": "assets/new-year-2026.jpg",
    "imageTitle": "ご案内"
  }
]
```

- 画像は `assets/` に置きます。対応形式はjpg・jpeg・png・webp・gifです。ファイル名は半角英数字・ハイフン・アンダースコアを使用してください。
- `imageTitle` がある画像リンクは拡大表示に対応します。画像はクリックされるまで読み込みません。
- PDFへのリンクも利用できます。その場合は `imageTitle` を付けません。
- 外部リンクは `https://` のURLを指定します。新しいタブで開きます。
- 参照する画像・PDFが存在しない場合は、生成を中止します。

## 更新漏れの確認

```powershell
node playful-site/scripts/build-news.mjs --check
node --test playful-site/scripts/build-news.test.mjs
```

`--check` はファイルを書き換えず、データとHTMLの不一致を検出します。HTML内の `NEWS:...:START` と `NEWS:...:END` に挟まれた範囲は自動生成のため直接編集しません。それ以外のレイアウトは、これまでどおりHTML・CSSで調整できます。

## 読み込みについて

閲覧時にJSONを取得する仕組みではなく、更新時に通常のHTMLを生成します。追加の通信やJavaScriptの処理を待たずに本文を読めます。JavaScriptが無効でも、記事本文・年別の開閉・電話・添付リンクは利用できます。
